# Curso de Data Science — Coderhouse

Repositorio académico con ejercicios, entregas y trabajo final desarrollados durante el curso de Data Science.

## Funcionalidades principales

- Prácticas de Python y funciones
- Análisis con NumPy y pandas
- Lectura y transformación de datos
- Visualización de información
- Series de tiempo y data wrangling
- Notebooks de entregas parciales y proyecto final
- Datasets y presentación de respaldo

## Tecnologías

Python, Jupyter Notebook, pandas, NumPy y bibliotecas de visualización.

## Uso

Abrir los archivos `.ipynb` con Jupyter Notebook, JupyterLab o Google Colab.

## Estado del proyecto

Repositorio de trabajo y evolución del proyecto. Algunas integraciones pueden requerir variables de entorno o servicios externos configurados por el propietario.
